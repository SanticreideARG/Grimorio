CONVENCIONES DE ASSETS
======================
- Cada imagen tiene un .txt al lado con el prompt LISTO para copiar/pegar
  (ya incluye el ancla de estilo). El PNG final va con el MISMO nombre base.
  Ej:  heroes/guerrera.txt  ->  heroes/guerrera.png
- Mantené el ancla de estilo idéntica en todos (ver _STYLE.txt) para cohesión.
- Resolución sugerida: retratos 768x1024, enemigos/jefes 1024x768,
  eventos 1280x720, cartas 768x1024, iconos/UI 512x512 (fondo transparente).
- Para agregar contenido: copiá _TEMPLATE.txt de la carpeta, renombralo al id
  que usás en los datos y completá el cuerpo del prompt.
